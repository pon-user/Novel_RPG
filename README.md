# 潮境の命珠（仮）｜遊べるノベルRPGプロトタイプ v0.1

**4人編成・装備・5ラウンド事前予約・戦闘結果をつないだ静的Webプロトタイプ。**

## まず遊ぶ

- **最も簡単：** `shiozakai_play_single.html` を開く。1ファイルでCSS・キャラ設定・敵データ・ブラウザ戦闘エンジンを含み、通信しない。
- **プロジェクト版：** `index.html` を開く。`styles.css` / `data.js` / `samples.js` / `art.js` / `battle.js` / `app.js` を同じディレクトリに置く。
- スマートフォンで継続利用するなら、GitHub Pages 等のHTTPS静的ホスティングにプロジェクトのWeb用ファイルをアップロードしてSafariで開く。iOSの「ファイル」プレビューでHTMLが正しく実行されない場合は、HTTPSで開く。

## 遊び方

1. **「物語を読む」**で港の仮ストーリーを進める。重装兵E01、呪術師E04、双壁E03と戦う。
2. **「編成と装備」**で主人公＋仲間3人を選ぶ。武器／防具／装飾品は計30種。6つのプリセット（装備なしを含む）も使える。
3. **「戦闘準備」**で主人公の命珠と敵遭遇を選び、ラウンド1〜5の4人分の技能・対象を予約。
4. 「5Rを実行する」を押すと、決定論的に戦闘を計算する。結果画面でラウンド別HP・戦闘ログを見られる。
5. E03とE04には **「攻略例を読み込む」** ボタンがある。両方の勝利をブラウザ戦闘エンジンで再検証済み。攻略例は自由に編集可能。
6. 「敵図鑑・試験」で17遭遇を自由に実行可能。敗北しても何度でも再挑戦できる。

## 今回採用した敵の変更範囲

- **E03 S9：** 虚像の盾 HP275・無音の処刑者 HP740・斥候 HP185。物理無効・魔法無効と各ラウンドの固定行動を保持。
- **E04 C13：** 呪術師はR1全体魔防弱体、**R2とR4に全体毒**、R3魔法全体、R5単体魔法。鈍足魔法破壊者は別の魔法スクリプト。
- **E01/E02/E05〜E15/EP-A/EP-B：** 直近R3の試験構成を保持。
- **EP-Bの「75%削って5R生存なら勝利」案は不採用。** 5R以内の敵全滅のみを勝利とする。

## 継承したキャラクター／戦闘の前提

- 仲間ID02（熊獣人盾）・03（犬使いの少女／戦術支援）・04（藤色の長髪／魔法攻撃）・05（青年／状態制御）・06（鋭い短髪／物理攻撃）・07（淡金髪／魔法防御と浄化）。主人公は銀白のショートヘア。**全員の固有名は仮名。**
- 4人編成（H＋02〜07の3人）、全20編成。04のMATK=130、06のPATK=130（v11からの試験基準）。最大5R、各ユニーク技能は原則1戦1回。
- 03/05には正式合意済みS5技能係数、E05/E06にP1限定耐性。異なる対象能力群のバフは**乗算重複**、同一群の同符号効果は強い方を採用。
- 庇護・広域護衛・挑発のみ優先度＋1。同じ優先度の中ではSPD降順。
- 毒は対象の**行動機会の後**にダメージが発生する。
- 07の浄化成功時にPATK/MATK＋20%、対象の次の2行動（状態持続は行動に応じて消費）。
- 02の従来 `02.05 鉄壁` / `02.06 破砕` を維持。試験中の `02.11 攻防一体` / `02.12 広域護衛` を別IDで用意。

## イラストの差し替え

既存の別案キャラのイメージ（髪型・役割など）は反映しているが、以前作成した**元画像ファイルとの対応が未確定**なので、今回のビルドはCSSの仮ビジュアル。**AI特有の金色の編み飾り等を勝手に追加した立ち絵ではない。**

正式な立ち絵を追加するときは `assets/characters/` へ画像を置き、`art.js` の `CHAR_ART` でIDごとのパスを設定。たとえば `H: 'assets/characters/hero.png'` 。画像がまだないキャラは引き続き仮ビジュアルを使用。

## プロトタイプとして未実装／要検証

- **19時などの定刻更新は未実装**。試験のため戦闘をその場で実行する。
- ノベルのメイン／サブの時系列、分岐の永続保存、スキル習得、レベル上昇、正式な戦闘アニメ・SEは未実装。
- **元のPython仮想エンジンをそのままブラウザで動かしているわけではない。** Python試作を参照してJavaScriptへ移植したもの。敵の特殊アクション・バフ期限・反射・敵状態異常などの境界挙動について**全条件の計算一致は未検証**。今回は操作・UI接続の叩き台。
- 各敵のLv1全編成の勝率を再測定したものではない。「攻略例」はこのブラウザ用エンジンでの勝利実例。正式版のバランス評価にそのまま転用しない。
- セーブはブラウザのlocalStorage。アカウント同期やクラウド保存なし。
