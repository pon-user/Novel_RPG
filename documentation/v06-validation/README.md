# MVP v0.6 — 実装・検証報告

2026-10-31。基準はNovel_RPG main `9ea01e7`（v0.5）。[仕様差分・参照SHA・A/B/C/D対応表](../v06-specification.md)に沿ってUIを改善した。今回mainへのマージ・GitHub Pages公開は行わない。Obsidianの正本・PR・作業ファイルは未変更。

## 1. 画面構成の変更前後

| 観点 | v0.5 | v0.6 |
|---|---|---|
| ホーム | 読書中心画面と開始カード | 進捗別の入口・現在地・現在の持ちもの・足あと。読書／戦闘へ再開 |
| 物語 | 原稿改行を1つの`p`へpre-wrap | 原稿とページ境界を保ち、通常段落・台詞・◇を別要素へ。段落余白は約0.5em、場面余白は約1.4em |
| スマートフォン | 章一覧が上部、一部情報が非表示 | 下部ナビ。現在地・持ちものはホームへ。本文のスクロール領域はナビの上で終わり、重ならない |
| 戦闘準備 | 5つの選択欄が中心 | 参戦者の役割・HP・能力、技能要約／詳細、予約一覧、ルール・NPC準備／発動表 |
| 戦闘 | 結果を先に表示、ログ初期閉じ | 正確な開始状態→各行動を全ターン初期展開→ユーザーが結果を開く |
| 履歴 | 読了節から同じ画面へ | 独立した履歴一覧と読み返し。進行・取得物を変更しない |
| 設定 | セーブと文字サイズ | 既存の入出力を維持し、一般操作・保存ヘルプを集約 |

ゲーム画面からバージョン、試遊版、内部ID、宝玉なし、未来の未所持品等の開発説明を除いた。NPC自由編成・装備・プリセット・将来機能の空ボタンは追加していない。

## 3. 配色比較と採用理由

| 案 | 本文／背景 | コントラスト | 判断 |
|---|---|---:|---|
| 明るい紙色 | `#242a25` / `#fffdf7` | **14.41:1** | 採用。白に近い暖色と濃い文字で明朝体を読みやすくし、外側の紙色と本文を区別 |
| 白と墨色 | `#202620` / `#ffffff` | 15.45:1 | 比較案。数値は最大だが、紙色案でも目標4.5:1を十分上回る |
| 淡いセピア | `#352b22` / `#f3ead7` | 11.55:1 | 比較案。暖色が強いため、より白に近い本文面を採用 |

通常段落は17px（スマホ）／18px（PC）、行高1.95、横幅上限40em。通常の空行は画面上で反復せず、台詞と段落を保つ。◇だけ明確な余白を置く。選択中ナビは太字・印・枠線、無効ボタンは破線と近傍の案内を併用する。自動アニメーションは追加せず、`prefers-reduced-motion`にも対応する。

## 4. 戦闘エンジンと保存への影響

- `prologue-state.js` と `prologue-story-v04.js` はmainから変更していない。保存キー・schema・正式48,391文字・節順・戦闘境界・v0.5ページ番号はそのまま。
- エンジンに `telemetry` を追加し、行動前にコピーした状態、実行順の行動・対象・HP前後・効果期間を保持する。旧`logs`・`states`・`metrics`・数値計算・技能・固定編成は維持。
- 追加情報を除く**674予約すべての旧結果**のSHA-256は `17deaf3c018e411bf01d030c7adf884bea7f9bf154d0b2c704b4124f430f1cfc` で、v0.5の固定期待値と完全一致。
- 旧セーブの履歴には予約が残らないため、合法な予約を探索し、保存済みのHP・ログ・結果と厳密一致する再演から表示情報を作る。結果を書き換えたり、新しい戦闘を進行として確定したりしない。一致しない記録では開始状態を捏造せず、保存済みログだけを表示する。
- セーブJSONの任意の追加telemetryは信用しない。UIは既存事実との一致を確認した再演データを利用し、`turns:null`や偽の集計値が混ざっても画面を壊さず、偽の振り返りを表示しない。
- 画面位置・結果開示・折畳は別のsessionStorageキーで管理し、ゲーム進行の初期化やセーブschema移行を必要としない。
- 振り返りの「防御や牽制の働き」は、同じ一撃で効果を1つだけ除いた場合との計算差。2要因の差を足して全戦闘の因果と断定しない。主画面は実被害・回避回数などの観測事実を優先。

## 8. 残課題・未承認事項

- v0.6のiPhone Safari実機の読みやすさ・操作感・面白さはレビュー後にユーザー確認が必要。Chromiumの幅・タッチ試験を実機Safari成功と呼ばない。WebKitの追加実行は未実施。
- 正式な序章人物画像は未提供。名前入りの代替表示を採用し、画像制作は別作業。
- 全674予約が勝つ既存の導入難度は維持。撃破T・被害差の表示改善が今回の範囲で、難易度調整の係数・敵HP等は未承認。必要なら別の比較シミュレーションと提案を行う。
- 本編の仲間／装備／バッグ拡張／敵図鑑完成／追憶再戦／地図・第1章・定刻19時は今回未実装。実装されているような空画面は作らない。
- 原稿に既存の半角／全角や人物表記があっても、今回のUI変更で原稿自体は訂正しない。
- ブラウザの任意データ削除・sessionStorage消失時は表示位置や折畳だけが既定へ戻る。ゲーム進行は既存localStorageセーブとJSONバックアップで保持する。
